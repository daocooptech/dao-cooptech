# Прототип ДАО КООПТЕХ: правила правок

66 статических страниц, без сборки и без фреймворка. Открывается двойным кликом по файлу и должен работать без сети.

## Слои стилей — главное правило

`styles.css` — структура и раскладка. `theme.css` — оформление, **все** токены `:root` и мобильная адаптация (`@media (max-width: 900px)`).

**Одно свойство объявляется ровно один раз.** Не дублируй правило в обоих файлах: `theme.css` подключается позже, и объявление из `styles.css` всё равно не применится — получится мёртвый код, который вводит в заблуждение следующего.

Если у компонента уже есть родня в одном файле (`.sign-side.signed` в `styles.css`), новый модификатор ставь рядом с ней, а не в другом файле.

## Шапка и сайдбар — не править в страницах

Эталонов два:
- `tools/shell.html` — авторизованный вид: шапка плюс сайдбар;
- `tools/shell-public.html` — лендинг, вход, регистрация, восстановление пароля, портал: шапка без сайдбара.

Разносятся скриптом:

```bash
python tools/sync-shell.py          # разнести по страницам
python tools/sync-shell.py --check  # только проверить, что всё совпадает
```

Какой пункт меню подсвечен на какой странице — `tools/_active.json`. Новую страницу обязательно допиши туда.

## Иконки

Берутся по атрибуту `data-icon` у ссылки (словарь `NAV_ICONS` в `app.js`), а не по тексту подписи: подпись меняется, иконка не должна отваливаться.

## Тема

Ставится `theme-init.js` синхронно в `<head>`, до первой отрисовки. Без явного выбора пользователя страница следует за системной `prefers-color-scheme`; выбор пишется в `localStorage` под ключом `cooptech_theme`. Тёмная тема — блок `html[data-theme="dark"]` в `theme.css`.

Проверяй обе темы. Цвет, заданный только в одной, — ошибка.

## Ресурсы только локальные

Шрифты (`fonts/` плюс `fonts.css`), фотографии и аватары (`images/`) лежат в репозитории. Внешних зависимостей при показе сайта нет — не возвращай ссылки на CDN, шрифты Google и фото-сервисы. Их уже убирали, когда сервис отдал 500 и половина страниц осталась без картинок.

## Набор состояний экрана

Компоненты общие, разметка объявляется атрибутами, писать своё не нужно.

| Что показать | Компонент |
|---|---|
| Сообщение над содержимым (ждём вторую сторону, ошибка, готово) | `.notice` + `.wait` / `.error` / `.ok` |
| Свежесть данных из чужой учётной системы | `.sync-note` + `.stale` / `.offline` |
| Загрузка | `.skeleton`, у контейнера `aria-busy="true"` |
| Кнопка в работе | `aria-busy="true"` плюс `aria-disabled`, но **не** `disabled` — иначе фокус срывается на `<body>` |
| Пусто | `.empty-state` (+ `.is-error`), внутри `.empty-ico` / `.empty-title` / `.empty-text` / `.empty-actions` |
| Подтверждение действия | атрибуты `data-confirm`, `data-confirm-text`, `data-confirm-ok`, `data-confirm-word`, `data-confirm-done` |
| Обратимое действие | `Coop.toast('текст', откатФункция)` — тост с отменой вместо вопроса |
| Озвучивание | `Coop.say('текст')`, срочное — `Coop.say('текст', true)` |

Дисциплина цвета: **серый — не поломка, золотой — ожидание, красный — ваше решение.** Красный редок; если он на экране, от человека ждут действия.

Подтверждаем то, что меняет обязательства: приёмку, отзыв подтверждения, отмену сделки, спор, отклик, заявление в пайщики, выход из кооператива, взаимозачёт, удаление аккаунта. Для обратимого — тост с отменой.

## Слова, которых не должно быть на экране

Узел, реплика, событие, синхронизация, федерация, консенсус, подпись ключом, хэш. Кооператор видит не «узел недоступен», а «ООО «Мириталь» сейчас не отвечает, показываем данные от вчера, 18:30».

## Доступность

Один `<h1>` на страницу. `.sr-only` для того, что должно звучать, но не показываться. `:focus-visible` с токеном `--focus`. Цвет никогда не единственный носитель смысла — рядом текст или форма (пунктир, половина полосы). Ошибка поля: `aria-invalid` на поле, `aria-describedby` на текст ошибки, `role="alert"` на самом тексте.

## Проверка результата

Отчёт «сделано» без измерения ничего не стоит. Минимум:

```bash
python tools/sync-shell.py --check
```

плюс в браузере: сравнить высоты карточек в ряду, проверить `scrollWidth > clientWidth` на 375, 1200 и 1440, посмотреть консоль на ошибки, пройтись по обеим темам. Скриншот вместо измерения не годится — расхождение в пару пикселей на нём не видно, а ряд из-за него разъезжается.

| `tools/fill-catalogs.py` | Наполнение каталогов объектами |
